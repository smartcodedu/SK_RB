1 Смена дня и ночи автоматически 🌑 → ☀️

Предварительно, создай Script с именем DayTime в папке со всем скриптами

📄 Скопируй в Script (DayTime) 

    Time = 0
    while true do
        game.Lighting.ClockTime = Time
        Time = Time + 0.01
        if Time > 24 then Time = 0 end
        wait()
    end

3 Работа фонарного столба по ночам

Внимательно проверь чтобы скрипт был внутри объекта с освещением

📄 Скопируй в Script (Lamp) 

    local SpotLight = script.Parent.SpotLight

    while true do
        local time = game.Lighting.ClockTime
        if time >= 18 or time < 6 then
            SpotLight.Enabled = true
        else
            SpotLight.Enabled = false
        end
        wait()
    end

4 Автоматическое мигание факелов

Скрипт добавь к объекту с эффектом огня.

📄 Скопируй в Script (Fire) 

    while true do
        script.Parent.Fire.Enabled=false
        wait(2)
        script.Parent.Fire.Enabled=true
        wait(2)
    end

5 Включение освещения в доме, когда мы внутри

Внимательно с объектами освещения и платформы, их именами и положением

📄 Скопируй в Script (HomeLight) 

    function onTouch(who)
        game.Workspace.House.Part1.SpotLight.Enabled=true	
    end
    
    function onTouchEnded(who)
        game.Workspace.House.Part1.SpotLight.Enabled=false	
    end

    game.Workspace.House.Platform_1.Touched:Connect(onTouch)
    game.Workspace.House.Platform_1.TouchEnded:Connect(onTouchEnded)
